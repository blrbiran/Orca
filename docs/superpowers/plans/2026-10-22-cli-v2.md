## Global Constraints

- Verification is `npm test` (Rule 18; typecheck included). Never `npm run verify`. Every run: `> $LOGS/<name>.log 2>&1`,
  then read the whole file (Rule 14). Report skipped files and "0 selected" verbatim (Rule 12).
- Each new branch: name the mutation that deletes it and see it red (Rule 9), mutations only in a `git clone --local`
  copy (Rule 15); restoration proved by `git diff | wc -c` and `git diff --cached | wc -c` = 0.
- Old names removed with **no aliases** (human ruling). Unknown command ⇒ `did you mean orca <x>?`, exit 1.
- `orca panel run|install|start|stop|restart|uninstall|status|logs` and `orca user …` are **unchanged**. The service
  launches `node dist/cli.js panel run --service <args>` (`src/service/render.ts:30`); **no `service.json` args change in
  this plan.** The bare alias `orca panel <run args>` (`src/cli.ts:557`) stays (it is not in spec §4's removed list).
- Out-of-repo writes (Rule 17): only `$ORCA_PERSON_DIR` (default `~/.orca/person`; dir `0700`, file `0600`, temp+rename,
  existing file's mode untouched). Tests set `ORCA_PERSON_DIR` to a temp dir; none touches `~/.orca`.
- Exit codes (§7, R8): 0 ok, 1 refused locally, 2 panel answered an error, 3 crash; per-command exceptions recorded in the
  registry: `dev resume` 2 = measurement changed, `dev chain start` 0–4, `decision metrics` 6, `decision validate`
  2 = downgraded, `dev gate` 2 = block, `dev check-append-only` 1 = rejected.
- `--json` prints exactly one line `{schema:"orca-cli-response-v1", status, commandId?, body, request?}`; no automatic
  JSON when stdout is not a TTY.
- New refusal codes, verbatim: `task-run-moved` (409), `control-person-token-required` (403),
  `control-person-token-invalid` (401), `control-dispatched-run-refused` (403); headers `x-orca-person-token`,
  `x-orca-dispatched-run`; env `ORCA_DISPATCHED_RUN`, `ORCA_PERSON_DIR`.
- A worktree branched before Task 7 fails a chain's gate check by design (`src/chain/gateCheck.ts:35`); the human
  recreates or rebases such worktrees. Put this in the Task 7 commit body and the handoff.
